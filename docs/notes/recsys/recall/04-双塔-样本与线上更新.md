# 双塔模型：正负样本、线上服务与模型更新

## 1. 正样本

正样本通常是用户已经产生正向行为的物品，例如：

```text
曝光并点击
收藏
加购
购买
完播
点赞
```

不同正向行为可以设置不同权重：

```text
点击 < 收藏 < 加购 < 购买
```

## 2. 负样本

### 简单负样本

常见来源：

```text
全体物品随机采样
Batch 内其他用户的正样本
```

优点是构造简单、训练高效；缺点是容易过于简单。

### 困难负样本

困难负样本通常是：

```text
被召回，但被后续排序淘汰的物品
旧模型召回但用户未选择的相似物品
与正样本同类目、同主题的物品
```

它们更接近用户兴趣，能帮助模型学习更细的区分边界。

### 假负样本

需要注意：

```text
未点击 ≠ 不喜欢
```

用户没点击可能是因为位置靠后、没有看到、时间不足或已经点击了其他物品。因此，曝光未点击不宜全部作为强负样本。

## 3. 线上服务

### 离线侧

```text
全部物品特征
        ↓
物品塔批量计算
        ↓
item embedding
        ↓
构建 HNSW / IVF-PQ 等 ANN 索引
```

### 在线侧

```text
用户实时特征和历史行为
        ↓
用户塔生成 user embedding
        ↓
ANN 检索 TopK 物品
        ↓
过滤已看、已买、下架和低质物品
        ↓
进入粗排 / 精排
```

## 4. 全量更新

全量更新会更新双塔模型的全部参数：

\[
\theta_{t+1}
=
\theta_t-\eta\nabla_\theta L(D_t;\theta_t)
\]

更新内容通常包括：

```text
用户 ID Embedding
物品 ID Embedding
用户塔参数
物品塔参数
```

典型流程：

```text
使用最近一天或一段时间的数据
        ↓
加载旧模型继续训练
        ↓
重新计算物品向量
        ↓
重建 ANN 索引
        ↓
发布新模型和新索引
```

全量更新负责适应整体数据分布变化。

## 5. 增量更新

增量更新主要处理用户近期兴趣变化。

常见方式是：

```text
锁住全连接层
只更新用户 ID Embedding
```

数学表示：

\[
E_u'
=
E_u-\eta\frac{\partial L}{\partial E_u}
\]

增量更新优点：

- 更新快；
- 成本低；
- 能较快反映近期兴趣。

不足：

- 只能解决部分用户兴趣变化；
- 无法替代整体模型更新；
- 容易受短期噪声影响。

## 6. 实际系统中的组合

实际系统通常采用：

```text
定期全量更新
+
高频增量更新
+
实时行为特征
```

三者分工：

```text
全量更新：适应整体分布变化
增量更新：更新用户长期表示
实时特征：捕捉最近几分钟的兴趣
```

## 7. 常见误区

- 全量更新通常是加载上一版模型继续训练，不等于每天从零训练。
- 1 epoch 不是固定规则，需要根据数据量和收敛情况决定。
- 增量更新不等于真正实时，实时推荐仍需要最近行为特征。
- 用户塔、物品塔、物品向量和 ANN 索引必须保持版本兼容。
- 单次偶然点击不应大幅改变用户兴趣，可采用平滑更新：

\[
E_u'
=
(1-\alpha)E_u+\alpha E_u^{new}
\]

## 8. 核心总结

```text
正样本：用户发生明确正向行为的物品。

简单负样本：随机物品或 Batch 内其他物品。

困难负样本：与用户兴趣接近，但最终未被选择的物品。

线上服务：用户塔在线计算，物品塔离线计算，ANN 完成召回。

全量更新：保证模型整体正确。

增量更新：保证用户兴趣足够新鲜。
```
