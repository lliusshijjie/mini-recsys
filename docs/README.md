# docs/

Learning notes, mind maps, and project documentation for mini-recsys.

## Layout

| Directory | Purpose |
|-----------|---------|
| `project/` | mini-recsys-specific plans, architecture, and design docs |
| `notes/` | General recommendation-system learning notes (Markdown) |
| `mindmaps/` | XMind mind maps |
| `snippets/` | Standalone experiments and code drafts (not production `src/`) |

## Suggested note topics

- `notes/01-basics/` — glossary, metrics, evaluation
- `notes/02-recall/` — vector search, collaborative filtering, multi-channel recall
- `notes/03-ranking/` — feature engineering, rule-based and ML ranking
- `notes/04-rerank/` — diversity, exploration, re-ranking
- `notes/05-system/` — storage, serving, deployment
