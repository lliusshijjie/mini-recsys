# docs/

mini-recsys 的学习笔记、思维导图与项目文档。

## 目录说明

| 目录 | 用途 |
|------|------|
| `project/` | mini-recsys 项目计划、架构与设计文档 |
| `notes/` | 推荐系统通用学习笔记（Markdown） |
| `mindmaps/` | XMind 思维导图 |
| `snippets/` | 独立实验与代码草稿（非生产 `src/`） |
